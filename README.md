# 基多拉摧毀松本城

電影故事專題：從山崎貴童年觀看《三大怪獸 地球最大決戰》的記憶，理解基多拉與松本城的創作緣分。

## 網頁內容

- 上下兩頁、共八格的訪談改編連續漫畫，可點圖放大。
- 六段電影故事，附導演訪談、東寶、松本電影委員會與松本城官方資料來源。
- 使用者提供的14張松本城實景照片，已完成水平校正。
- 哥吉拉閱讀配樂：WaterTower Music 官方 YouTube 播放器，2019年《哥吉拉 II：怪獸之王》的 Godzilla Main Title 版本；支援播放、暫停與音量調整。
- Open Graph 與 Twitter Card 分享預覽。

漫畫及主視覺為 AI 概念插畫與訪談改編，非電影劇照、非正式電影分鏡。影像分析與導演訪談說法已在頁面中區分。音樂由原官方播放器提供，本儲存庫不含擷取的音訊檔。
